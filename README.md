# Virginia Studies Quest

A colorful, animated browser quiz for Virginia Studies VS.6. It contains all 36 questions from the printable flashcards and uses Captain Hoot, a Virginia landscape illustration, sound effects, scoring, streaks, and confetti.

## Play

Open `index.html` in a modern browser, or serve this folder as a static website. Choose Quick for 10 questions, Adventure for 20, or Master to play all 36. Use the number keys 1-4 or click an answer.

The game has no build step or external service dependency. Keep `index.html`, `app.js`, `questions.js`, `styles.css`, and the `assets` folder together when sharing or hosting it.
